# Download Name Restorer

一个 Chrome / Edge Manifest V3 下载扩展。

用途：

- 某些站点下载后文件名是哈希值或 UUID。
- 这个扩展会在浏览器下载阶段，尽量改回用户看到的原始文件名。

当前策略：

- 优先读取服务器响应头 `Content-Disposition`。
- 页面加载时预采集附件链接与候选文件名映射，避免“点击后消息晚到”导致错过重命名。
- 捕获用户点击下载链接时的候选文件名（`download`、`title`、`sudyfile-attr`、链接文本、附近上下文）作为实时补充。
- 针对高校 CMS 附件页补充从列表项、表格行、正文容器提取候选名。
- 只有当浏览器建议文件名看起来像哈希值时才改名，减少误改。

## 安装

1. 打开 Chrome 或 Edge。
2. 进入扩展管理页。
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择目录 `D:\Desktop\下载重命名`。

## 文件

- `manifest.json`: 插件清单
- `background.js`: 下载重命名核心逻辑
- `content.js`: 下载点击上下文采集
- `popup.html` / `popup.js`: 快捷开关与当前网站一键加入白名单
- `options.html` / `options.js` / `options.css`: 设置页（模式、白名单和黑名单）

## 开关与模式

- 在 popup 可以直接启用/停用插件。
- popup 中可点击 `将当前网站加入白名单`，把当前标签页域名一键加入白名单。
- 设置页支持三种模式：
- `全部网站生效`: 全站生效。
- `仅白名单生效`: 仅对白名单域名生效。
- `黑名单排除`: 全站生效，但黑名单域名排除。

域名规则：

- 每行一个域名。
- 支持 `*.example.com` 通配写法。
- 可直接粘贴 URL，保存时会自动归一化为域名。

## 限制

- 如果站点既不返回原始文件名，也不在页面暴露任何可推断信息，无法还原真实名称。
- 某些脚本化下载（blob、二次跳转接口）可能需要额外站点规则。
