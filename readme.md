# Download Name Restorer

一个 Chrome / Edge Manifest V3 下载扩展。

用途：

- 某些站点下载出来的文件名是哈希值或 UUID。
- 这个扩展会在浏览器下载阶段，尽量把文件名改回原始文件名。

当前策略：

- 优先读取服务器返回的 `Content-Disposition` 文件名。
- 如果页面上的下载链接带有 `download`、`title`、`aria-label`，或者链接文字本身就是文件名，也会在点击时记录下来，下载时用于重命名。
- 针对高校 CMS 附件页，会额外从链接附近的列表项、表格行、段落文本、附件区块和页面标题中提取候选文件名。
- 仅当浏览器当前建议的文件名看起来像哈希值时才会改名，避免误改正常文件。

适用示例：

- 像 `https://pg.njupt.edu.cn/.../1ab758b5-cbe5-487d-bfb1-7ee3be7e5ffa.doc` 这类链接，URL 最后一段是 UUID。
- 但如果用户是在页面里点击一个文字为 `xxx.doc` 的链接下载，扩展现在会优先把这个文字当成真实文件名。
- 如果链接文字只是“下载”或“附件”，扩展会继续尝试从同一条附件列表、同一段落或页面标题中推断真实文件名。

## 安装

1. 打开 Chrome 或 Edge。
2. 进入扩展管理页。
3. 打开“开发者模式”。
4. 选择“加载已解压的扩展程序”。
5. 选中当前目录 `D:\Desktop\下载重命名`。

## 文件

- `manifest.json`: 插件清单
- `background.js`: 下载重命名核心逻辑
- `content.js`: 记录页面点击下载时的原始文件名

## 限制

- 如果站点既没有返回原始文件名，也没有在页面链接上暴露 `download` 文件名，扩展无法凭空推断真实名称。
- 某些站点通过脚本、blob 或接口二次跳转下载文件时，可能需要针对具体站点继续补充规则。
- 当前规则重点覆盖高校常见的 WebPlus / WebCMS 类文章和附件页面，不保证对所有站点都同样稳定。
